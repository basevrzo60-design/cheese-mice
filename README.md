# หนูชีส — Cheese Mice

เกมออนไลน์ 4–12 คน ใช้ React/Vite และ Express/Socket.IO ผู้เล่นแต่ละคนเห็นเฉพาะบทบาท เวลาตื่น และข้อมูลลับของตัวเอง

## เล่นในเครื่อง

```bash
npm ci
npm run dev
```

เปิด `http://localhost:5173` หรือใช้ IP ของเครื่องในเครือข่ายเดียวกันบนมือถือ เซิร์ฟเวอร์ใช้พอร์ต 3000 หน้าเว็บ development ส่ง Socket.IO ผ่าน Vite proxy

```bash
npm run build
npm start
```

หลัง build เซิร์ฟเวอร์ให้บริการหน้าเว็บด้วยที่ `http://localhost:3000`

## เล่นบนมือถือ

1. เปิดเซิร์ฟเวอร์บนคอมพิวเตอร์ด้วย `npm run build` แล้ว `npm start`
2. ให้มือถือกับคอมพิวเตอร์อยู่ในเครือข่ายเดียวกัน แล้วเปิด `http://IP-ของคอมพิวเตอร์:3000` ใน Safari หรือ Chrome บนมือถือ (อย่าใช้ `localhost` บนมือถือ)
3. สร้างห้องหรือกรอกรหัสห้องเพื่อเล่น ผู้เล่นแต่ละคนใช้เบราว์เซอร์ของตัวเอง

หน้าเกมรองรับจอแคบ 320px ขึ้นไป มีปุ่มขนาดอย่างน้อย 44px ช่องกรอกขนาดตัวอักษร 16px และกดค้างที่รหัสห้องเพื่อคัดลอกได้เมื่อเบราว์เซอร์ไม่อนุญาต Clipboard ผ่าน HTTP

ถ้าเปิดผ่าน IP ไม่ได้ ให้ตรวจว่าพอร์ต 3000 ได้รับอนุญาตในไฟร์วอลล์ของเครื่องและเครือข่ายไม่ได้แยกอุปกรณ์ออกจากกัน สำหรับเล่นคนละเครือข่าย ให้เปิดจาก URL ของบริการที่ deploy ตาม [DEPLOYMENT.md](DEPLOYMENT.md) แทน IP ภายในบ้าน

## กติกาและโหมด

หน้าเกมแสดงผู้เล่นนั่งรอบโต๊ะกลมและชีสกลางโต๊ะ กลางคืนทั้งโต๊ะจะมืด เมื่อถึงเวลาตื่นของคุณ โต๊ะจะสว่างและเห็นเฉพาะคุณกับคนที่ตื่นเวลาเดียวกัน ผู้ที่ตื่นคนเดียวแตะผู้เล่นรอบโต๊ะเพื่อดูเวลาได้ ข้อมูลช่วงตื่นของคนอื่นยังเป็นความลับ รองรับโต๊ะ 4–12 ที่นั่งและจอมือถือ

ปุ่มและข้อมูลของแต่ละขั้นตอนอยู่ในแถบซ้ายข้างโต๊ะ ตั้งแต่ห้องรอ ทอยเวลา ไปจนถึงโหวตและผลเกม การเลือกการ์ดในโหมด 1 เปิดเป็นหน้าต่างอัตโนมัติ ปิดแล้วเปิดใหม่จากปุ่ม “เลือกการ์ดบทบาท” ได้ เมื่อเลือกแล้วหน้าต่างจะปิดเพื่อให้ดูบทบาทและกดพร้อมจากแถบซ้าย

- โหมด 1: เลือกการ์ดคว่ำคนละ 1 ใบ มีหนูโจร 1 ใบ จากนั้นทุกคนทอยเวลาตื่น 1–6 และเล่นกลางคืนตั้งแต่ตี 1 ถึง 6 โมงเช้า ตื่นคนเดียวดูเวลาคนอื่นได้ 1 คนจนกว่าจะกดพร้อม ส่วนผู้ที่ตื่นพร้อมกันต้องกดพร้อมครบทุกคนจึงเปลี่ยนเป็นช่วงเวลาถัดไป
- หลัง 6 โมงของโหมด 1 หนูโจรเลือกลูกสมุนตามจำนวนผู้เล่น: 4–6 คนมีลูกสมุน 1 คน, 7–9 คนมี 2 คน และ 10–12 คนมี 3 คน ก่อนเริ่มประชุมและโหวต
- โหมด 2: เจ้าของห้องเป็นแอดมิน ไม่ได้รับบทบาท ไม่ทอยเวลา และไม่ร่วมโหวต จำนวนที่นั่งรวมแอดมิน ผู้เล่นคนอื่นสุ่มบทบาท ดูบทบาทแล้วกดพร้อม จากนั้นทอยเวลาตื่น แอดมินเห็นบทบาท เวลา และสถานะทุกคน เลือกลูกสมุนได้ตั้งแต่ 0 คนถึงผู้เล่นทุกคนที่ไม่ใช่โจร กดบันทึก และแก้ไขได้ก่อนเปิดโหวต ต้องบันทึกลูกสมุนก่อนเปิดให้โหวต ไม่มีช่วงกลางคืนหรือตัวจับเวลา
- ทุกบทบาทลงคะแนนได้คนละ 1 เสียง ผู้ที่ได้คะแนนสูงสุดถูกจับ หากเป็นหนูโจร หนูธรรมดาชนะ หากเป็นคนอื่นหรือคะแนนเสมอ ฝ่ายโจรชนะ
- บอททำขั้นตอนส่วนตัวอัตโนมัติและโหวตแบบสุ่ม เพิ่มบอทใน lobby ได้ หากเตะระหว่างเกม ที่นั่งนั้นจะกลายเป็นบอทโดยคงบทบาทและเวลาตื่นไว้

## การกลับเข้าห้อง

บันทึกโทเคนที่นั่งใน localStorage ของเบราว์เซอร์เดิม เปิดหน้าใหม่หรือเครือข่ายกลับมาจะคืนที่นั่งอัตโนมัติ ระหว่างคนหลุดเกมจะหยุด เจ้าของห้องสามารถแทนที่คนนั้นด้วยบอทได้ โทเคนเดิมจะใช้ไม่ได้เมื่อถูกเตะ/แทนที่

ห้องอยู่ในหน่วยความจำและหายเมื่อเซิร์ฟเวอร์รีสตาร์ต ห้องที่ไม่มีผู้เล่นออนไลน์เกิน 24 ชั่วโมงจะถูกปิด ไม่รองรับการคืนที่นั่งจากเบราว์เซอร์หรืออุปกรณ์อื่น

ในโหมด 2 ระหว่างรอบ แอดมินที่หลุดยังคงเป็นเจ้าของห้อง เกมจะหยุดรอแอดมินกลับมาที่ที่นั่งเดิม ข้อมูลลับจะไม่ถูกโอนไปให้ผู้เล่นคนอื่น

## ตรวจสอบ

```bash
npm test
npm run lint
```

Socket.IO namespace คือ `/cheese` และ health check คือ `/health` ตั้ง `CLIENT_ORIGIN` เป็นรายการ origin ที่อนุญาตคั่นด้วยจุลภาค หากไม่ตั้งจะอนุญาต origin ทุกแห่งสำหรับการเล่นในเครื่อง ดู [.env.example](.env.example) และ [DEPLOYMENT.md](DEPLOYMENT.md)

## GitHub / Vercel / Render

Vercel ใช้ `npm run build:client` สำหรับหน้าเกม ส่วน Render ใช้ `npm run build:server` และ `npm start` สำหรับ Socket.IO ตั้ง `VITE_SERVER_URL` บน Vercel ให้ชี้ backend และ `CLIENT_ORIGIN` บน Render ให้ตรงหน้าเกม ดู [DEPLOYMENT.md](DEPLOYMENT.md) สำหรับ URL และค่าของโปรเจกต์หนูชีสใหม่นี้
